#Klarna Payment POC

This is a full end-to-end POC (Proof of Concept) showing how Klarna payments 
actually work in a production-style Android project.

──────────────────────────────────────

🔧 WHAT WE BUILT

──────────────────────────────────────

✅ Native Android App (Kotlin + Jetpack Compose)

✅ MVI + Clean Architecture with SOLID principles

✅ Koin for Dependency Injection

✅ All 3 Klarna payment methods — Pay Later, Pay Now, Pay Over Time

✅ Spring Boot Kotlin Backend API

✅ Swagger / OpenAPI documentation

✅ Auto browser launch with status page on startup

✅ Klarna Playground (sandbox) integration

──────────────────────────────────────

📱 ANDROID TECH STACK

──────────────────────────────────────
- Kotlin + Jetpack Compose
- MVI + Clean Architecture (Domain / Data / Presentation)
- Koin 3.5 — Dependency Injection
- Klarna Mobile SDK 2.11.5
- Retrofit + OkHttp
- StateFlow / Coroutines
- Navigation Compose

──────────────────────────────────────

⚙️ BACKEND TECH STACK

──────────────────────────────────────
- Spring Boot 3.3 (Kotlin)
- WebClient (WebFlux) for Klarna API calls
- SpringDoc OpenAPI — Swagger UI
- REST API — POST /api/session + POST /api/order
- Environment variable based credentials
